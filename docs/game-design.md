# 《无限融合变异捕鱼》设计讨论整理

更新日期：2026-09-28。本文记录本次讨论的最终方向、已确定规则，以及尚未定稿的数值和边界。当前代码仅初始化模块，并不代表以下玩法已实现。

## 1. 定位与驱动力

面向粉丝群，几乎纯群指令操作。以原有捕鱼为本体，保持简单：金币、经验与等级支撑成长，随机鱼群提供惊喜，渔具和工具提供收集目标。

核心循环：每日投饵满足鱼群要求 → 公共鱼群刷新 → 群友捕鱼获取收益 → 第一位有资格的捕获者贡献变异刻度 → 满刻度生成新鱼种 → 新鱼进入池子继续被捕获与变异。

金币用于商店和道具抽奖，道具及装备回到捕鱼、变异循环。吸引力来自抓稀有鱼、收集渔具、参与新鱼诞生，以及把自己的性状留在鱼种与族谱里。

不再沿用最初讨论的牧场、专属动物三选一、每日探索或更深区域方案。原创内容由捕鱼过程自然产生，不靠不断制作新区域、战斗和副本推动。

## 2. 鱼池与公共鱼群

- 初始池子只有一个鱼种。
- 继承原捕鱼的鱼群机制，每日投饵数量满足要求即可；具体门槛、刷新频率、鱼群容量与持续时间后续核对旧实现。
- 鱼由玩家实际捕获，单抽／十连／百连不直接产出鱼。
- 新变异鱼种加入池子，亲代鱼种保留。
- 每个鱼种有稀有度，影响公共鱼群刷新的权重。稀有度还可关联捕鱼难度与收益，具体数值待定。
- 同一种鱼再次刷新成新的鱼群时，获得新的变异贡献机会。

术语区分：鱼种是族谱和变异进度的主体；鱼群是一次刷新实例。限制“只有第一个人贡献”针对每次鱼群，不是某鱼种一生只允许一次贡献。

## 3. 变异进度与贡献资格

每个鱼种独立维护 0%～100% 的变异刻度及本轮贡献榜。这里的“与你有关”，只指你是该鱼生成时的两名性状贡献者之一，不指曾经捕过它，也不沿所有祖先无限继承。

按以下优先级判定基础贡献：

| 条件 | 基础贡献 |
| --- | --- |
| 当前鱼种的性状贡献者包含你 | 0% |
| 当前鱼种任意直接子代的性状贡献者包含你 | 0% |
| 不满足上述条件，但当前鱼种的直接亲代性状贡献者包含你 | 1% |
| 其余情况 | 5% |

“直接子代／直接亲代”仅看一层。0% 规则优先于 1% 规则。根鱼没有亲代，不适用亲代减速条件。

### 每次鱼群只结算一次有效贡献

1. 捕鱼失败不贡献，也不占用机会。
2. 捕获成功但基础贡献为 0%：正常结算捕鱼收益，机会顺延。
3. 第一位能提供正贡献的成功捕获者：按基础刻度、变异力和道具效果增加刻度，消耗该鱼群的贡献机会。
4. 1% 也是有效贡献，会消耗机会，不等待后续 5% 玩家。
5. 后续玩家正常捕鱼并获得收益，不再增加该鱼群对应的变异刻度。
6. 全部捕获者都不具备资格时，本次鱼群没有变异贡献。

原先“第一人贡献 0% 也消耗机会”的提议已被修正，以允许顺延为准。

### 满刻度生成

- 达到 100% 时，从本轮贡献榜选出实际贡献刻度最高的两位不同玩家。
- 根据二人的群名片特征生成原创奇幻鱼的性状、名字与外形，保留亲代关联和三色遗传。
- 原鱼种本轮刻度归零，开始下一轮；历史贡献与本次诞生记录保留。
- 新鱼种是该鱼种的直接子变异，拥有自己的变异进度，族谱记录每一代关系。
- 贡献排名依据实际增加的刻度，不按捕获次数。只剩 3% 时，名义贡献 10% 也只计入 3%，溢出不计排名、不带到下一轮。

未定边界：只有一名贡献者时的生成策略、并列排名的裁决、AI 失败后的补偿／重试，以及满刻度等待生成期间的后续结算。实现前明确，不能默认为复制同一人填满两个名额。

## 4. AI 原创性状与三色遗传

鱼不是从预设物种名单中选取。AI 以贡献前两名的群名片为主要性状来源，可结合头像可见特征，以及已有且可用的用户画像，生成原创奇幻鱼。当前方案不再包含用户选动物三选一。

每条鱼固定保存三个特征颜色：

| 颜色 | 来源 |
| --- | --- |
| 颜色 1 | 第一贡献者头像的代表色 |
| 颜色 2 | 第二贡献者头像的代表色 |
| 颜色 3 | 亲代鱼三个特征色的等权平均色 |

本鱼的三色再等权平均，成为它下一代的“亲代颜色”。因此每代两位新贡献者各占三分之一的直接色彩输入，既有祖先痕迹，也有新参与者特征。

头像提色建议使用图像算法取主要色块的代表色，不对整张图片直接求平均；降低背景的干扰，保留黑白头像本来的黑白灰。AI 使用传入的确定色值生成设定和图像。

讨论中的实现建议：三色在 OKLab 色彩空间等权混合，再转换为可显示色值；绘制时可分别对应主色、斑纹和鳍尾。具体部位映射尚未锁定。保存生成时的头像代表色和名片快照，换头像／名片不追溯修改已诞生鱼种。

根鱼初始配色、头像读取失败的备用色、具体画像来源、AI 服务与是否同步生成鱼图尚待确定。AI 文案不直接决定经济数值。

## 5. 稀有度与族谱深度推理

已确定：变异鱼存在稀有度差异，稀有度影响刷鱼权重，每一代保留族谱。不设已确定的硬性代数上限。

建议方案：新鱼独立抽取稀有度，不默认“越深越稀有”。普通／稀有／珍稀权重 10／3／1 只是讨论示例，并非配置。若按单鱼种权重抽样，则某鱼概率为其权重除以池内权重之和；鱼种数量会影响各稀有度的整体占比。

形状推理：

- 父鱼保留且可以多次诞生子代，所以树可以向宽处生长。
- 老鱼直接子代越来越多，相关贡献者逐渐失去为老鱼贡献的资格，进度更容易转向新分支。
- 原 0% 规则下，A/B 和 C/D 两组可交替沿同一分支繁衍。
- 加入亲代关联 1% 后，两组交替会受到减速；第三组参与接力可避开这一限制，因此它抑制少数人快速延长分支，但不禁止深树。
- 无装备／道具加成时，全部 5% 贡献需要 20 次有效鱼群贡献，全部 1% 需要 100 次。这里是有效鱼群次数，不是总捕鱼次数。
- 渔力、变异力及实际活跃人数都会改变速度，上述次数不是最终平衡保证。
- 鱼种增加会分散单鱼种进度，且许多捕获不再贡献。应观察新鱼诞生间隔、有效贡献率、鱼种数量和族谱深度，再决定调整，不先增加区域系统。

## 6. 金币、经验与等级

等级系统沿用捕鱼，不另设探索等级、区域层数等成长线。现有代码参考为主仓 `src/libraries/fishgame/player.py`：升级需求 `int((level + 19) * 1.1 ** (level / 10))`，经验达到需求后扣除对应经验，可连续升级。

继承等级机制不等于自动迁移旧玩家存档。新游戏初始金币、捕鱼奖励、等级对渔力的加成及旧账号迁移策略尚未确定。

金币用途：购买商店廉价道具，以及单抽／十连／百连抽取道具与装备。珍贵道具主要靠抽。抽奖不是购买捕鱼次数，也不直接替代捕鱼。

## 7. 商店、抽奖与消耗品

已确定：商店提供比较便宜的道具；珍贵道具靠抽；支持单抽、十连、百连；保留每日投饵与鱼群机制。

以下是讨论中的候选道具，不是已锁定的完整掉落表：

| 道具 | 建议来源 | 建议作用 |
| --- | --- | --- |
| 普通饵料 | 商店、普通抽奖档 | 累计每日投饵量 |
| 优质饵料 | 抽奖 | 一份抵多份普通饵料 |
| 稀有诱饵 | 珍贵抽奖档 | 提高下一次公共鱼群刷新时稀有鱼的权重 |
| 定向诱饵 | 珍贵抽奖档 | 提高指定已诞生鱼种的公共刷新权重 |
| 变异饵 | 珍贵抽奖档 | 本次有效变异贡献翻倍；0% 仍为 0% |

诱饵影响公共鱼群，不能悄悄变成每人独立抽鱼。定向诱饵用于追指定分支，不需要为每条原创鱼手工制作配置。

变异饵只在实际贡献刻度时消耗：捕鱼失败、因关联为 0%、或鱼群机会已被别人用掉，都不消耗。具体装备／预先使用方式、与变异力的叠加方式待定。

抽奖应包含可收集渔具与工具；奖池概率、价格、保底、十连／百连是否有优惠、重复消耗品数量均未确定。此前“百连逐条直接抓鱼”的方案已废弃。

## 8. 渔具、工具与双属性

已确定：增加装备部位，大量外观变体作为收集品；核心属性为渔力、变异力。

| 属性 | 职责 |
| --- | --- |
| 渔力 | 影响捕鱼能力及难抓鱼的捕获判定，具体继承旧公式时核对 |
| 变异力 | 提高获得有效贡献机会后增加的变异刻度，不绕过关联限制 |

建议首版六部位：鱼竿、鱼线、鱼钩、浮漂、渔轮、鱼篓，每个部位一件。工具是否占其中部位或作为消耗品，以及最终部位数量未锁定。

同档装备可分高渔力、高变异力、均衡型。外观和名字可大量扩充，但先不叠加套装、强化、词条洗练等系统。商店提供基础款，抽奖提供珍贵款。

变异力建议公式：`实际贡献（截断前） = 基础刻度 × (1 + 变异力 / 100)`。100 变异力让 5% 变为 10%、1% 变为 2%，0% 不变。此公式与系数是讨论方案，正式数值待定。

重复装备自动换金币是候选处理方式，尚未锁定。无论最终采用哪种方式，避免让大量换皮装备带来过重的背包操作。装备切换时机、属性结算快照及加成上限需在实现时明确。

## 9. 实现约束与待定事项

实现时需保障：

- 群级鱼群与鱼种进度正确保存；贡献资格、鱼群机会占用、刻度增加、道具扣除需原子结算，避免多人同时首捕重复贡献。
- 每轮变异有唯一标识，防止满刻度重复生成子代；AI 调用不能长期占住捕鱼锁，失败必须可恢复。
- 保存鱼种 ID、亲代 ID、两位贡献者身份及生成时快照、三色和混合色、稀有度、诞生轮次、贡献记录；名字可重复，ID 不可混用。
- 账号关联使用稳定身份标识，名片仅参与内容生成；跨适配器绑定策略待实现阶段确认。
- 不直接复用旧捕鱼 Redis 键，防止串改旧存档。
- Web、QQ 命令使用同一套规则；首版以群命令为主，暂不要求玩家 Web 界面。

实施前仍需定稿：鱼种和族谱按群隔离还是全局共享；根鱼设定；稀有度分布；每日投饵／刷新参数；缺少两名贡献者与贡献并列规则；变异力数值与道具叠加；渔具最终部位和掉落表；抽奖经济参数；AI 及头像来源。本文没有替用户擅自确定这些边界。
