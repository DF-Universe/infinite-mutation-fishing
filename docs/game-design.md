# 《无限融合变异捕鱼》设计讨论整理

更新日期：2026-09-28。本文记录本次讨论的最终方向、已确定规则，以及尚未定稿的数值和边界。当前已实现捕获、变异生成、商店抽奖及两槽装备，运行细节以 README 为准。

后续实现更新：已接入群捕获核心与 WebP 展示，当前可用范围见 README。最新规则优先：普通鱼仅一人捕获成功后消失，仅 Fever 多人可尝试；单人贡献封顶 99%，第二人参与后才允许达到 100%；并列贡献随机排名；每次名义贡献乘 0.85～1.0 浮动，按实际增量记账。

## 1. 定位与驱动力

面向粉丝群，几乎纯群指令操作。以原有捕鱼为本体，保持简单：金币、经验与等级支撑成长，随机鱼群提供惊喜，渔具和工具提供收集目标。

核心循环：每日投饵满足鱼群要求 → 公共鱼群刷新 → 群友捕鱼获取收益 → 第一位有资格的捕获者贡献变异刻度 → 满刻度生成新鱼种 → 新鱼进入池子继续被捕获与变异。

金币用于商店和道具抽奖，道具及装备回到捕鱼、变异循环。吸引力来自抓稀有鱼、收集渔具、参与新鱼诞生，以及把自己的性状留在鱼种与族谱里。

不再沿用最初讨论的牧场、专属动物三选一、每日探索或更深区域方案。原创内容由捕鱼过程自然产生，不靠不断制作新区域、战斗和副本推动。

## 2. 鱼池与公共鱼群

- 初始池子只有一个鱼种。
- 继承原捕鱼的鱼群机制，每日投饵数量满足要求即可；每日最多投饵 5 份，19:30 按份数/5 判定 Fever，满 5 必定；持续 60～120 分钟。
- 鱼由玩家实际捕获，单抽／十连／百连不直接产出鱼。
- 新变异鱼种加入池子，亲代鱼种保留。
- 每个鱼种有稀有度，影响公共鱼群刷新的权重。稀有度基础难度为 0/30/100，收益规则见第 8 节。
- 同一种鱼再次刷新成新的鱼群时，获得新的变异贡献机会。

术语区分：鱼种是族谱和变异进度的主体；每次刷新有独立捕获状态，普通状态为一条鱼，Fever 状态为可供多人捕获的鱼群。限制“只有第一个人贡献”针对每次刷新，不是某鱼种一生只允许一次贡献。

## 3. 变异进度与贡献资格

每个鱼种独立维护 0%～100% 的变异刻度及本轮贡献榜。这里的“与你有关”，只指你是该鱼生成时的两名性状贡献者之一，不指曾经捕过它，也不沿所有祖先无限继承。

按以下优先级判定基础贡献：

| 条件 | 基础贡献 |
| --- | --- |
| 当前鱼种的性状贡献者包含你 | 0% |
| 当前鱼种任意直接子代的性状贡献者包含你 | 0% |
| 不满足上述条件，但当前鱼种的直接亲代性状贡献者包含你 | 1% |
| 其余情况 | 5% |

“直接子代／直接亲代”仅看一层。0% 规则优先于 1% 规则。根鱼没有亲代，不适用亲代减速条件。

### 每次鱼群只结算一次有效贡献

1. 捕鱼失败不贡献，也不占用机会。
2. 捕获成功但实际贡献为 0%：正常结算捕鱼收益；Fever 机会顺延，普通鱼仍被捕走。
3. 第一位能提供正贡献的成功捕获者：按基础刻度、变异力和道具效果增加刻度，消耗该鱼群的贡献机会。
4. 1% 也是有效贡献，会消耗机会，不等待后续 5% 玩家。
5. Fever 后续玩家正常捕鱼并获得收益，不再增加该轮对应的变异刻度；普通鱼捕获成功后已不存在。
6. 全部捕获者都不具备资格时，本次鱼群没有变异贡献。

原先“第一人贡献 0% 也消耗机会”的提议已被修正，以允许顺延为准。

### 满刻度生成

- 达到 100% 时，从本轮贡献榜选出实际贡献刻度最高的两位不同玩家。
- 根据二人的群名片特征生成原创奇幻鱼的性状、名字与外形，保留亲代关联和三色遗传。
- 原鱼种本轮刻度归零，开始下一轮；历史贡献与本次诞生记录保留。
- 新鱼种是该鱼种的直接子变异，拥有自己的变异进度，族谱记录每一代关系。
- 贡献排名依据实际增加的刻度，不按捕获次数。只剩 3% 时，名义贡献 10% 也只计入 3%，溢出不计排名、不带到下一轮。

已补充：只有一名贡献者时封顶 99%，同一人继续捕获不再加刻度，直至另一人贡献；贡献并列随机排序。贡献乘 0.85～1.0 的浮动后再按上限截断。满刻度等待生成期间暂停该鱼种的新贡献，排名和任务持久化保存。用户已明确授权名片／昵称、提取色值和亲代设定传给 DeepSeek，自动生成已接入；不发送 QQ 号、群号或头像原图。

## 4. AI 原创性状与三色遗传

后续确认：鱼图使用程序绘制的固定简笔画模板，通过替换三种特征色复用，不使用 AI 生图。AI 仅承担名片归纳、命名与性状文案。祖先鱼暂定名“初源鱼”，预览配色为身体浅青绿 `#71C9BE`、斑纹奶油黄 `#FFE3A1`、鳍尾珊瑚粉 `#F49A8F`；造型和配色待用户看图确认。图中的中性描边与眼睛不计入三种遗传色。

鱼不是从预设物种名单中选取。AI 以贡献前两名的群名片为主要性状来源，可结合头像可见特征，以及已有且可用的用户画像，生成原创奇幻鱼。当前方案不再包含用户选动物三选一。

每条鱼固定保存三个特征颜色：

| 颜色 | 来源 |
| --- | --- |
| 颜色 1 | 第一贡献者头像的代表色 |
| 颜色 2 | 第二贡献者头像的代表色 |
| 颜色 3 | 亲代鱼三个特征色的等权平均色 |

本鱼的三色再等权平均，成为它下一代的“亲代颜色”。因此每代两位新贡献者各占三分之一的直接色彩输入，既有祖先痕迹，也有新参与者特征。

头像提色建议使用图像算法取主要色块的代表色，不对整张图片直接求平均；降低背景的干扰，保留黑白头像本来的黑白灰。程序把确定的色值填入简笔画模板。

讨论中的实现建议：三色在 OKLab 色彩空间等权混合，再转换为可显示色值；绘制时可分别对应主色、斑纹和鳍尾。已采用身体／斑纹／鳍尾映射。保存生成时的头像代表色和名片快照，换头像／名片不追溯修改已诞生鱼种。

根鱼初始三色为 #71C9BE / #FFE3A1 / #F49A8F；使用群名片及头像，头像失败回退亲代对应色位。DeepSeek 文案传输字段已经用户明确授权，见 README。AI 文案不直接决定经济数值。

## 5. 稀有度与族谱深度推理

已确定：变异鱼存在稀有度差异，稀有度影响刷鱼权重，每一代保留族谱。不设已确定的硬性代数上限。

当前子代独立抽取稀有度，初始权重 R/SR/SSR=100/25/5，不随代数加深而提高。自然刷新与子代生成分开配置：用户指定各档总出率 1%/0.2%/0.05%，先按档出率判定，再在该档鱼种间按难度加权。鱼种数量不改变各档总出率；没有鱼种的档位暂不出鱼。

形状推理：

- 父鱼保留且可以多次诞生子代，所以树可以向宽处生长。
- 老鱼直接子代越来越多，相关贡献者逐渐失去为老鱼贡献的资格，进度更容易转向新分支。
- 原 0% 规则下，A/B 和 C/D 两组可交替沿同一分支繁衍。
- 加入亲代关联 1% 后，两组交替会受到减速；第三组参与接力可避开这一限制，因此它抑制少数人快速延长分支，但不禁止深树。
- 无装备／道具加成时，全部 5% 贡献需要 20 次有效鱼群贡献，全部 1% 需要 100 次。这里是有效鱼群次数，不是总捕鱼次数。
- 渔力、变异力及实际活跃人数都会改变速度，上述次数不是最终平衡保证。
- 鱼种增加会分散单鱼种进度，且许多捕获不再贡献。应观察新鱼诞生间隔、有效贡献率、鱼种数量和族谱深度，再决定调整，不先增加区域系统。

## 6. 金币、经验与等级

等级系统沿用捕鱼，不另设探索等级、区域层数等成长线。现有代码参考为主仓 `src/libraries/fishgame/player.py`：升级需求 `int((level + 19) * 1.1 ** (level / 10))`，经验达到需求后扣除对应经验，可连续升级。

继承等级机制不等于自动迁移旧玩家存档。新游戏按群独立存档，从 1 级、0 金币开始，不迁移旧捕鱼账号；等级直接加入渔力，Fever 时取等级整除 5。

金币用途：购买商店廉价道具，以及单抽／十连／百连抽取道具与装备。珍贵道具主要靠抽。抽奖不是购买捕鱼次数，也不直接替代捕鱼。

## 7. 商店、抽奖与消耗品（已定稿并实现）

商店出售四档渔具和普通／白银食料，黄金食料只靠抽。三种食料通过「使用」投放，全群每天最多 5 份，每份计一次。Fever 时不可投；已有食料效果时需「强制使用」覆盖。普通／白银／黄金食料沿用旧版持续时间与稀有度加成。

单抽 10 金币出 1 件，十连 100 出 11 件，百连 1000 出 110 件。奖池保留旧版五种工具、三档食料、三档强化剂和三档加成卡，删除未接入内容后归一化权重。渔具只在商店出售；抽奖不产鱼。不接工坊、神秘商店、积分、荧光棒。早期定向诱饵、变异饵及一份抵多份等候选方案均未采用。

强化剂增加渔力，按捕鱼尝试次数消耗，失败亦消耗。加成卡按时长增加成功捕获的金币与经验。同类覆盖、不同类共存。完整数值与命令见 README 和数据文件。

## 8. 渔具、工具与双属性（最新范围）

仅保留渔具和工具两个槽位，取消早期六部位方案。渔具沿用渔力 10/20/40/80，不加变异力；五种工具沿用渔力 5/10/20/40/60，并增加等额变异力。装备可反复换装或卸下，重复物品堆叠保留，不自动折现。

渔力影响捕获成功率。变异力提高有效贡献：`基础刻度 × (1 + 变异力/100) × 0.85～1.0 随机浮动`，再受 99% 单人限制与剩余刻度截断；不会绕过关联限制，也不会使同次刷新产生第二次有效贡献。

新鱼固定难度为 `稀有度基础难度 + 贡献者平均等级`，R/SR/SSR 基础为 0/30/100。平均等级在满刻度时冻结，计算包含本次捕鱼升级后的等级，不累加亲代难度。奖励按旧鱼数据分稀有度拟合：R=难度+10、SR=2×难度、SSR=3×难度，向下取整；金币与经验同步增加。

## 9. 实现约束与待定事项

实现时需保障：

- 群级鱼群与鱼种进度正确保存；贡献资格、鱼群机会占用、刻度增加、道具扣除需原子结算，避免多人同时首捕重复贡献。
- 每轮变异有唯一标识，防止满刻度重复生成子代；AI 调用不能长期占住捕鱼锁，失败必须可恢复。
- 保存鱼种 ID、亲代 ID、两位贡献者身份及生成时快照、三色和混合色、稀有度、诞生轮次、贡献记录；名字可重复，ID 不可混用。
- 账号关联使用稳定身份标识，名片仅参与内容生成；跨适配器绑定策略待实现阶段确认。
- 不直接复用旧捕鱼 Redis 键，防止串改旧存档。
- Web、QQ 命令使用同一套规则；首版以群命令为主，暂不要求玩家 Web 界面。

已定稿并实现：鱼池、玩家与族谱按群隔离；祖先鱼初始设定；投饵与刷新；单人 99% 与并列随机规则；两槽装备、双属性与道具；抽卡经济；DeepSeek 文案与头像取色。当前不提供玩家 Web 页面，也不增加工坊、神秘商店等玩法。
